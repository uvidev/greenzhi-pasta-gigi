# Website Resmi Greenzhi Pasta Gigi (PT. Shuang Hor Indonesia)

Website modern dan responsif untuk promosi dan pendaftaran distributor resmi **Greenzhi Toothgel**, dibuat berdasarkan materi lengkap dari [greenzhipastagigi.com](https://www.greenzhipastagigi.com/).

---

## 🌟 Fitur-Fitur Utama

1. **Header & Sticky Glass Navigation**:
   - Menu lengkap: **Beranda**, **Produk & Bahan**, **Sejuta Manfaat**, **Peluang Bisnis**, **Testimoni Video**, **Edukasi/Artikel**, **Legalitas**.
   - Tombol cepat: **Daftar Distributor** & **Chat WhatsApp (08994622195)**.
   - Mobile menu responsif dengan drawer interaktif.

2. **Produk & 8 Bahan Alami Unggulan**:
   - Penjelasan mendalam tentang *Nano-Ganoderma Lucidum (Lingzhi)*, *Ekstrak Miswak (Siwak)*, *Aloe Vera*, *Ekstrak Neem*, *Garam Bambu*, *Klorofilin*, *Silitol*, dan *Peppermint Oil*.
   - Panduan metode *Dry Brushing* (menyikat gigi kering tanpa dibasahi air).
   - Edukasi perbandingan Plak Gigi vs Karang Gigi.

3. **Sejuta Manfaat & Multi-Khasiat (Filter Tab Interaktif)**:
   - Filter tab untuk: *Kesehatan Gigi & Gusi*, *Pertolongan Darurat & Kulit (Luka Bakar, Sengatan Lebah Madu, Ruam Bayi, Kaki Pecah)*, dan *Perawatan Hewan Peliharaan*.
   - Bukti foto nyata kisah sengatan lebah madu 13 Sept 2024.

4. **Peluang Bisnis Jutawan (Pola 1 - 10 - 5)**:
   - Edukasi modal terjangkau: Rp 72.000 / 11 PV per bulan.
   - **Kalkulator Cuan Interaktif**: Geser slider atau pilih preset tim (10, 100, 1.000, 10.000 orang) untuk melihat kalkulasi PV dan estimasi bonus bulanan secara live (hingga Rp 26.097.000 / bulan).
   - Penghargaan posisi *Double Diamond*: Trip luar negeri 2x setahun, mobil 4 tahun sekali, bonus internasional, dan hak waris.

5. **Galeri Testimoni Video YouTube**:
   - 6 video YouTube responsif testimoni asli konsumen dan dokter/praktisi.

6. **Formulir Pendaftaran Distributor Resmi**:
   - Form modal pop-up lengkap (KTP 16 digit, Nama, Tgl Lahir, WA, Alamat, RT/RW, Desa, Kecamatan, Kab/Kota, Provinsi, Kode Pos).
   - Validasi pintar dan otomatis meneruskan data pendaftaran yang terformat rapi ke WhatsApp Admin resmi (08994622195).

7. **Floating Action & Back-to-Top**:
   - Tombol melayang WhatsApp dengan efek animasi pulse di pojok kanan bawah.
   - Tombol kembali ke atas di pojok kiri bawah.

---

## 🚀 Cara Menjalankan

Anda dapat langsung membuka file `index.html` di peramban web (Google Chrome, Edge, dll.), atau menggunakan server lokal:

```bash
# Opsi 1: Menggunakan npx serve
npx serve .

# Opsi 2: Menggunakan python
python -m http.server 8080
```
Lalu buka `http://localhost:8080` atau `http://localhost:3000`.
